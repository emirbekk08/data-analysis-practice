# Практическая работа 1. Базовые команды Linux и работа с CLI

## Цели работы
- Ознакомление с интерфейсом командной строки (CLI) Linux.
- Изучение базовых команд навигации, управления файлами и директориями.

## Задания по вариантам

### Вариант A (Базовый уровень)
1. Выведите путь к текущей директории (pwd).
2. Создайте структуру папок: 	est_dir/subdir1 и 	est_dir/subdir2.
3. Создайте пустой файл ile1.txt в папке subdir1 с помощью 	ouch.
4. Скопируйте ile1.txt в папку subdir2 под именем ile2.txt.

### Вариант B (Средний уровень)
1. Выполните все шаги варианта A.
2. Создайте многострочный текстовый файл logs.txt с помощью cho и перенаправления вывода (>>).
3. Используя команду cat, выведите содержимое созданного файла на экран.
4. Выведите только первые 5 строк файла с помощью команды head.

### Вариант C (Продвинутый уровень)
1. Выполните все шаги вариантов A и B.
2. Используя команду grep, найдите определенное ключевое слово в файле logs.txt.
3. Настройте права доступа к файлу так, чтобы только владелец мог его читать и редактировать (chmod).
