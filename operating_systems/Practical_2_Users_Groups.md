# Практическая работа 2. Управление пользователями и группами в Linux

## Цели работы
- Изучение механизмов разграничения прав доступа в многопользовательской ОС.
- Работа с учетными записями пользователей и группами.

## Задания по вариантам

### Вариант A
1. Выведите список всех пользователей в системе из файла /etc/passwd.
2. Создайте нового пользователя 	estuser (требуются права root/sudo).

### Вариант B
1. Выполните шаги варианта A.
2. Создайте новую группу developers.
3. Добавьте пользователя 	estuser в группу developers.

### Вариант C
1. Выполните шаги вариантов A и B.
2. Измените владельца папки 	est_dir на пользователя 	estuser и группу developers (chown).
3. Настройте совместный доступ к директории.
