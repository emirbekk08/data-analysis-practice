# Практическая работа 4. Автоматизация задач с помощью планировщика Cron

## Цели работы
- Разбор синтаксиса конфигурационных файлов планировщика задач \cron\.
- Создание регулярных сценариев автоматизации обслуживания ОС.

## Задания по вариантам

### Вариант A
1. Откройте редактор задач cron текущего пользователя через \crontab -e\.
2. Настройте ежеминутный вывод текущей даты в файл \~/time.txt\ (команда \date >> ~/time.txt\).

### Вариант B
1. Выполните шаги варианта A.
2. Напишите скрипт, который раз в сутки делает резервную копию директории \	est_dir\ в архив \.tar.gz\.
3. Запланируйте запуск этого скрипта каждый день в 3:00 ночи.

### Вариант C
1. Выполните шаги вариантов A и B.
2. Настройте сбор логов выполнения ваших cron-задач.
3. Создайте задачу, которая запускается автоматически при каждой загрузке системы (\@reboot\).
