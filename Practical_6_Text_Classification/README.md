# Практическая работа №6 — Классификация текстов

## Цель работы
Изучить основные этапы классификации текстов и обучить модель машинного обучения для определения тональности текстов.

## Данные
- Язык текстов: русский.
- Источник: датасет с текстами и метками тональности.
- Целевая переменная: `sentiment`.
- Перед обучением удалялись пустые и повторяющиеся тексты.

## Использованные инструменты
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes

## Этапы выполнения
1. Загрузка и подготовка датасета.
2. Очистка текстов.
3. Разделение данных на обучающую и тестовую выборки в соотношении 80/20.
4. Преобразование текстов в числовые признаки с помощью TF-IDF.
5. Обучение классификатора Multinomial Naive Bayes.
6. Оценка качества модели с помощью Accuracy, Macro-F1 и отчёта классификации.
7. Сохранение результатов и обученной модели.

## Результаты
Численные значения метрик находятся в файле `metrics.csv`. Матрица ошибок и примеры неправильных предсказаний сохранены в соответствующих файлах результатов.

## Вывод
В ходе работы был создан конвейер обработки текстов, обучен классификатор и сохранены результаты оценки его качества.
